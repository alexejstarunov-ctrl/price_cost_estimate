# Смета на укладку плитки

Мобильное веб-приложение (PWA) для быстрого расчёта стоимости работ и материалов
по укладке плитки. Работает в браузере, ставится на телефон, считает офлайн.

**Открыть:** https://alexejstarunov-ctrl.github.io/price_cost_estimate/

Владельцу: как скопировать проект, обновлять расценки с помощью LLM и публиковать —
в [OWNER_GUIDE.md](OWNER_GUIDE.md). Инструкция для нейросети —
[.claude/skills/update-prices/SKILL.md](.claude/skills/update-prices/SKILL.md).

## Что умеет

- **Смета** — позиции, объём, цена за единицу, автоматический итог, скидка; сохраняется
  сама при каждом изменении
- **Несколько смет** — список по нажатию на название в шапке: новая, переключение,
  удаление целиком; резервная копия в файл и восстановление на другом устройстве
- **Свой каталог** — разделы сворачиваются и переставляются, позиции перетаскиваются за
  рукоятку в любое место, в том числе в другой раздел; раскладка запоминается на
  устройстве и попадает в резервную копию
- **Каталог расценок** — 47 позиций: подготовка основания, укладка, доп. работы, материалы;
  у каждой показан рыночный диапазон цен
- **Регионы** — Москва, Санкт-Петербург, Волгоград, Краснодар, Нижний Новгород,
  Ростов-на-Дону, Самара, Саратов, Тамбов и два обобщённых профиля. По семи городам —
  реальные цены по 10 ключевым позициям (помечены «прайсы города»), остальное по коэффициенту
- **Расчёт материалов** — плитка с запасом на подрезку по типу раскладки, клей по зубу
  гребёнки для вашего формата, затирка по формуле производителей, грунтовка, СВП
- **PDF для заказчика** — печатная форма со своими реквизитами; отправка текстом в мессенджер
- **Свой прайс** — карандаш у любой позиции: изменить цену, название, раздел, единицу; базовую
  позицию можно скрыть (и вернуть), свою — удалить; «+ В прайс» добавляет новую позицию с
  ценой; при добавлении в смету изменённую цену можно запомнить в прайсе одной галочкой
- **Шаблоны** — типовой санузел, фартук, балкон сохраняются и добавляются одним нажатием

Данные хранятся только на устройстве пользователя, в браузере. Сервера нет.

## Установка на телефон

**Android (Chrome):** откройте ссылку — приложение само предложит «Установить»
(кнопка есть и во вкладке «Ещё»). Иконка появится на экране, работает без интернета.

**iPhone (Safari):** откройте ссылку → внизу «Поделиться» → «На экран „Домой“».
Apple не даёт сайтам показывать системный диалог установки, поэтому приложение
показывает подсказку с этим путём. В установленном виде «Скачать PDF» открывает
смету в Safari — там доступны «Напечатать», «Сохранить в Файлы» и «Поделиться».

Своя позиция — материал или работа, которых нет в расценках, — добавляется прямо в
смету кнопкой «Своя позиция» (в смете и внизу каталога); галочка «Запомнить» кладёт её
в каталог как свою цену.

## Разработка

```bash
npm install
npm run dev            # локальный сервер
npm run check:prices   # проверка данных расценок (дубли id, нули, битые ссылки)
npm run build          # сборка в dist/
npm run scrape         # обновить public/prices.json
```

Стек: React 18, TypeScript, Vite, vite-plugin-pwa. Зависимостей в рантайме нет,
кроме React — PDF делается через печать браузера, без тяжёлых библиотек.

## Деплой

Пуш в `main` запускает `.github/workflows/deploy.yml` — сборка и публикация на
GitHub Pages. В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.

## Откуда берутся цены

Встроенная база — **средние рыночные ориентиры** по Москве (срез сентября 2026), собранные
из открытых прайс-листов подрядчиков.

Региональные цены (`src/data/regions.ts`) — из региональных страниц Профи.ру
(`profi.ru/geo-<город>/remont/plitochniki/price/`) и открытых прайсов местных бригад и
компаний, 2025–2026. Единый коэффициент для города врёт: в Ростове и Краснодаре укладка
стоит ~0,85 от Москвы, а затирка и демонтаж — ~0,5. Поэтому там, где есть реальная цена
города по позиции, ставится она, а коэффициент применяется только к остальному.

| Город | Коэффициент | Стена, м² | Пол, м² | Крупный формат, м² |
|---|---|---|---|---|
| Волгоград | 0,60 | 1 000 | 1 000 | — |
| Краснодар | 0,85 | 1 400 | 1 250 | 1 700 |
| Нижний Новгород | 0,72 | 1 200 | 1 050 | 2 000 |
| Ростов-на-Дону | 0,85 | 1 500 | 1 250 | 1 700 |
| Самара | 0,70 | 1 200 | 1 000 | 1 400 |
| Саратов | 0,62 | 1 000 | 850 | 1 400 |
| Тамбов | 0,50 | 880 | 700 | 1 000 |

Это не нормативные расценки ГЭСН/ФЕР и не оферта:
реальная цена зависит от объекта, объёма и мастера. Любую цену можно поправить прямо
в смете или завести свою.

`.github/workflows/prices.yml` раз в неделю запускает сборщик, который пытается
уточнить цены и пишет результат в `public/prices.json`. **Приложение работает и без
этого фида** — при недоступности источников остаются базовые расценки, ничего не ломается.

Про автоматический сбор с площадок объявлений — честно, чтобы не было ложных ожиданий:

| Источник | Статус | Причина |
|---|---|---|
| Профи.ру | выключен по умолчанию | Их пользовательское соглашение прямо запрещает парсинг. SEO-страницы `/price/` технически отдаются, но включать сбор — осознанное решение владельца репозитория (`ENABLE_PROFI=1`) |
| Авито | недоступен | Блокировка дата-центровых IP на уровне ASN. При проверке отдаёт `HTTP 429` даже с домашнего российского адреса, из GitHub Actions (диапазоны Azure) — тем более |
| Яндекс Услуги | недоступен | SPA + SmartCaptcha, `/search` и `/api/*` закрыты в `robots.txt` |

Публичного API нет ни у одной из трёх площадок: Avito API отдаёт только собственные
объявления авторизованного продавца, у Профи.ру и Яндекс Услуг API нет вовсе.

Практичный способ держать цены свежими — раз в квартал обновлять базу в
`src/data/works.ts` по открытым прайсам подрядчиков, как это делает и приложение-прототип
PriceFree, оговаривая «средние цены, полученные анализом рынка».
