# Смета на укладку плитки

Мобильное веб-приложение (PWA) для быстрого расчёта стоимости работ и материалов
по укладке плитки. Работает в браузере, ставится на телефон, считает офлайн.

**Открыть:** https://alexejstarunov-ctrl.github.io/price_cost_estimate/

## Что умеет

- **Смета** — позиции, объём, цена за единицу, автоматический итог, скидка
- **Каталог расценок** — 47 позиций: подготовка основания, укладка, доп. работы, материалы;
  у каждой показан рыночный диапазон цен
- **Регионы** — коэффициент к московским расценкам: СПб, миллионники, райцентры
- **Расчёт материалов** — плитка с запасом на подрезку по типу раскладки, клей по зубу
  гребёнки для вашего формата, затирка по формуле производителей, грунтовка, СВП
- **PDF для заказчика** — печатная форма со своими реквизитами; отправка текстом в мессенджер
- **Свои расценки** — собственный прайс мастера или бригады
- **Шаблоны** — типовой санузел, фартук, балкон сохраняются и добавляются одним нажатием

Данные хранятся только на устройстве пользователя, в браузере. Сервера нет.

## Установка на телефон

Откройте ссылку в браузере → меню → «Добавить на главный экран». Приложение
появится иконкой и будет работать без интернета.

## Разработка

```bash
npm install
npm run dev      # локальный сервер
npm run build    # сборка в dist/
npm run scrape   # обновить public/prices.json
```

Стек: React 18, TypeScript, Vite, vite-plugin-pwa. Зависимостей в рантайме нет,
кроме React — PDF делается через печать браузера, без тяжёлых библиотек.

## Деплой

Пуш в `main` запускает `.github/workflows/deploy.yml` — сборка и публикация на
GitHub Pages. В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.

## Откуда берутся цены

Встроенная база — **средние рыночные ориентиры** по РФ (срез сентября 2026), собранные
из открытых прайс-листов подрядчиков. Это не нормативные расценки ГЭСН/ФЕР и не оферта:
реальная цена зависит от объекта, объёма и мастера. Любую цену можно поправить прямо
в смете или завести свою.

`.github/workflows/prices.yml` раз в неделю запускает сборщик, который пытается
уточнить цены и пишет результат в `public/prices.json`. **Приложение работает и без
этого фида** — при недоступности источников остаются базовые расценки, ничего не ломается.

Про автоматический сбор с площадок объявлений — честно, чтобы не было ложных ожиданий:

| Источник | Статус | Причина |
|---|---|---|
| Профи.ру | выключен по умолчанию | Их пользовательское соглашение прямо запрещает парсинг. SEO-страницы `/price/` технически отдаются, но включать сбор — осознанное решение владельца репозитория (`ENABLE_PROFI=1`) |
| Авито | недоступен | Блокировка дата-центровых IP на уровне ASN. При проверке отдаёт `HTTP 429` даже с домашнего российского адреса, из GitHub Actions (диапазоны Azure) — тем более |
| Яндекс Услуги | недоступен | SPA + SmartCaptcha, `/search` и `/api/*` закрыты в `robots.txt` |

Публичного API нет ни у одной из трёх площадок: Avito API отдаёт только собственные
объявления авторизованного продавца, у Профи.ру и Яндекс Услуг API нет вовсе.

Практичный способ держать цены свежими — раз в квартал обновлять базу в
`src/data/works.ts` по открытым прайсам подрядчиков, как это делает и приложение-прототип
PriceFree, оговаривая «средние цены, полученные анализом рынка».
